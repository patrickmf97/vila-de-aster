# Vila de Aster — Estado do Projeto

## Visão
RPG 2D top-down para navegador, com estética chibi original, mundo vivo e foco em NPCs com rotinas, memória e inteligência própria.

## MVP atual
- Vila 2D jogável no navegador
- Personagem controlável
- Câmera seguindo o jogador
- Colisões
- HUD
- Ciclo de dia/noite
- 5 NPCs com profissões e rotinas
- Sistema de diálogo
- Afinidade
- Memória persistente em localStorage
- Primeiro evento narrativo: "O eco sob o rio"

## Direção aprovada
- Manter o jogo 2D top-down
- Preservar o visual atual dos personagens como base de identidade própria
- Priorizar mundo vivo, história e IA dos NPCs sobre complexidade gráfica
- Browser-first

## Próximo marco
Transformar o protótipo técnico em uma vertical slice pequena, mas com sensação de jogo real.
